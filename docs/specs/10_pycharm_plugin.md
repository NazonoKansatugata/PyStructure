# pycharm_plugin 仕様書

## 目的

PyCharm プラグインは、コア解析エンジンを利用する将来の IDE 統合層である。

## 責務

- IDE からプロジェクト解析を起動する。
- エディタ UI に構造情報と依存情報を表示する。
- IDE 固有の関心事と静的解析ロジックを分離する。

## 入力

- IDE から渡されるプロジェクトパスまたは選択スコープ。
- PyStructure コアからの解析データ。

## 出力

- モジュール、クラス、関数、依存関係のインタラクティブな表示。

## 挙動

- プラグインは解析コアに依存し、同等の処理を重複実装しない。
- UI 更新は ad hoc な解析ではなく、解析結果から導出する。
- IDE 統合はコア analyzer とは独立に進化できる。

## テスト観点

- プラグイン向けアダプタは core analysis とは分離してテストする。
- UI 統合では、コア出力が正しく表示されることを検証する。
