# call_analyzer 仕様書

## 目的

`call_analyzer` は、Python モジュール内の呼び出し関係を検出し、依存グラフを補強する役割を持つ。

## 責務

- AST から関数呼び出し、メソッド呼び出しを検出する。
- 可能な場合は呼び出し元と呼び出し先の情報を保持する。
- 呼び出し解析を定義抽出と分離する。

## 入力

- モジュールの Python AST。
- 解析対象となるモジュール、クラス、関数に関する文脈情報。

## 出力

- グラフのエッジや後続解決に利用できる呼び出しレコード。

## 挙動

- 生の AST ノードよりも、安定したシンボル名を優先する。
- コード実行や実行時値の推測は行わない。
- 静的に判定できない対象は unresolved として記録する。

## テスト観点

- 直接の関数呼び出しが検出されること。
- 可能な範囲でメソッド呼び出しが検出されること。
- 解決不能な式が安全に未解決として扱われること。
