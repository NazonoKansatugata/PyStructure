# cli 仕様書

## 目的

`cli` は、プロジェクト解析のためのコマンドライン入口を提供する。

## 責務

- コマンドライン引数を解析する。
- 指定されたルートパスに対してプロジェクト解析を実行する。
- 人間可読なテキスト、または JSON を出力する。

## 入力

- コマンドライン引数。

## 出力

- 終了ステータスコード。
- 標準出力に書き出されるテキストまたは JSON。

## 挙動

- `analyze` コマンドを主な入口とする。
- `--json` によって構造化 JSON 出力へ切り替える。
- 未知のコマンドは引数解析エラーとして失敗する。

## テスト観点

- 引数解析が analyze コマンドを受け付けること。
- JSON 出力に analysis と graph の両方が含まれること。
