# exporter 仕様書

## 目的

`exporter` は、解析結果や依存グラフを外部形式へ変換し、下流ツールで利用可能にする役割を持つ。

## 責務

- グラフデータを機械可読な出力へシリアライズする。
- 解析コードに export の責務を混ぜず、複数形式をサポートする。
- 可視化ツールに必要なメタデータを保持する。

## 入力

- 解析結果、および／または依存グラフ。

## 出力

- JSON、Graphviz、または将来追加される export 形式のシリアライズ結果。

## 挙動

- Exporter は状態を持たないか、最小限の内部状態に留める。
- 同じ入力に対して出力形式は安定している必要がある。
- 将来の exporter 追加で analyzer 側の変更は不要であるべき。

## テスト観点

- 生成された出力が対象形式として妥当であること。
- 該当する場合、グラフのメタデータが往復変換後も維持されること。
