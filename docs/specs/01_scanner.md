# scanner 仕様書

## 目的

`scanner` は、プロジェクトルート配下の Python ソースファイルを発見し、ファイルパスからモジュール名を導出する役割を持つ。

## 責務

- プロジェクトツリーを走査し、対象となる `.py` ファイルを収集する。
- 生成物や仮想環境に相当するディレクトリを除外する。
- ファイルパスを Python のモジュール名へ変換する。

## 入力

- `Path` として与えられるプロジェクトルートディレクトリ。
- `Path` として与えられるソースファイルパス。

## 出力

- ソート済みの Python ファイルパス一覧。
- 発見した各ファイルに対応するモジュール名文字列。

## 挙動

- `.git`、`venv`、`.venv`、`__pycache__`、`build`、`dist` などのディレクトリを無視する。
- `__init__.py` は `__init__` セグメントではなく、パッケージ名として扱う。
- 後続処理が安定するよう、決定的な順序で返す。

## エラー処理

- プロジェクトルート外のパスは受け付けない。
- 存在しないルートや不正なルートは、通常のファイルシステムエラーとして扱う。

## テスト観点

- 除外対象ディレクトリが走査されないこと。
- パッケージルートが正しくモジュール名へ変換されること。
- ネストしたモジュールがドット区切りのモジュールパスになること。
