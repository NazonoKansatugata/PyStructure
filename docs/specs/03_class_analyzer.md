# class_analyzer 仕様書

## 目的

`class_analyzer` は、Python ソースからクラス定義、基底クラス、メソッド定義を抽出する役割を持つ。

## 責務

- トップレベルのクラス定義を検出する。
- 基底クラス式を安定した文字列表現で保持する。
- クラス本体に直接定義されたメソッドを収集する。

## 入力

- モジュールの Python AST。

## 出力

- 名前、行番号、基底クラス名、メソッドを含むクラスレコード。

## 挙動

- メソッドの `async` 状態を保持する。
- クラスメソッドではないネスト関数は無視する。
- メソッド収集はクラス本体の範囲に閉じる。

## テスト観点

- 単一継承と多重継承が記録されること。
- インスタンスメソッドと async メソッドの両方が保持されること。
- ネストした定義がクラス出力へ混入しないこと。
