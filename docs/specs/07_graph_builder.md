# graph_builder 仕様書

## 目的

`graph_builder` は、解析結果をノードとエッジからなる依存グラフへ変換する役割を持つ。

## 責務

- モジュール、クラス、メソッド、関数のグラフノードを作成する。
- 定義関係や import 関係などの構造エッジを作成する。
- グラフをシリアライズ可能な形で提供する。

## 入力

- 解析済みモジュールレコードの一覧。

## 出力

- ノードとエッジを持つ依存グラフ。

## 挙動

- すべてのグラフ要素に対して安定した識別子を使用する。
- ノードにはソースパスと行番号のメタデータを保持する。
- 再実行時にも同じ入力から同じ出力が得られるよう決定的に構築する。

## テスト観点

- モジュール、クラス、メソッド、関数のノードが存在すること。
- 定義エッジが作成されること。
- 解決済み import から import エッジが作成されること。
