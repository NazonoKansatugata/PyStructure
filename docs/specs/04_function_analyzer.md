# function_analyzer 仕様書

## 目的

`function_analyzer` は、Python ソースからモジュールレベルの関数定義を抽出する役割を持つ。

## 責務

- トップレベルの `def` と `async def` を検出する。
- 関数名、行番号、async フラグを記録する。
- モジュール関数とメソッドを区別する。

## 入力

- モジュールの Python AST。

## 出力

- 名前、行番号、async 状態、種別を持つ関数レコード。

## 挙動

- 対象はモジュールレベル関数のみとする。
- クラスメソッドは class analyzer が担当する。
- 関数の順序はソース順を維持する。

## テスト観点

- 通常関数と async 関数が記録されること。
- メソッドがモジュール関数一覧に含まれないこと。
