# import_resolver 仕様書

## 目的

`import_resolver` は、import のメタ情報を完全修飾されたモジュールターゲットへ変換する役割を持つ。

## 責務

- ファイルパスからパッケージ名を解決する。
- 相対 import を絶対モジュールパスへ変換する。
- 解決処理を決定的かつファイルシステムベースに保つ。

## 入力

- プロジェクトルートのパス。
- 現在のファイルパス。
- 現在のモジュール名。
- 相対 import の階層と import されたモジュール名。

## 出力

- 解決されたモジュール名、または判定不能な場合の `None`。

## 挙動

- パッケージの `__init__.py` はパッケージモジュールとして扱う。
- パッケージ文脈からの相対 import を正しく解決する。
- 絶対 import はそのまま維持する。

## テスト観点

- パッケージ名とモジュール名が正しく解決されること。
- パッケージおよび通常モジュールからの相対 import が正しく解決されること。
